# Lemo-Opuscar films

The 720p demo films of the 99 styles in [Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar), one per style, named after the style's folder (`<slug>.mp4` for `styles/<slug>/`). GitHub Pages serves them at `https://lemomo-ai.github.io/lemo-opuscar-films/<slug>.mp4` for the gallery, https://lemomo-ai.github.io/lemo-opuscar/

They are made in the main repository and copied here by its `tools/films_repo.sh`: change them there, not here. The films at full quality are on the main repository's [films release](https://github.com/lemomo-ai/lemo-opuscar/releases/tag/films); each film's sources and credits are in `styles/<slug>/demo/CREDITS` there.
